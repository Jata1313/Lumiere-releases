# Lumière — installers and updates

Lumière is a free, private, offline activity tracker for Windows.

This repository only holds the **installers** and the **signed update files** that Lumière
downloads when you click "Install" in its update window. The source code is not here.

- Download: open the latest release on the right and run `Lumiere_<version>_x64-setup.exe`.
- Updates are signed: Lumière installs only files signed with its developer's key.
- Lumière checks for updates once a day; you can turn this off in Settings → About.
